# Sistema de Ignição Bluetooth para Minifoguetes

Projeto de um sistema de ignição remota utilizando ESP32 e comunicação Bluetooth, desenvolvido para aplicações em minifoguetes experimentais.

O objetivo do projeto é permitir o acionamento seguro de ignitores elétricos através de um dispositivo móvel ou terminal Bluetooth, incorporando múltiplas camadas de segurança e controle operacional.

---

## Funcionalidades

- Comunicação Bluetooth com ESP32
- Sistema de armamento/desarmamento
- Ignição manual remota
- Heartbeat de segurança
- Countdown para ignição
- Feedback serial em tempo real
- Estados operacionais organizados por máquina de estados
- Controle de relé/transistor de ignição
- Estrutura expansível para telemetria futura

---

## Objetivo Técnico

O projeto foi desenvolvido com foco em:

- sistemas embarcados

- eletrônica aplicada

Além da aplicação prática em foguetes experimentais, o sistema também serve como plataforma de estudo para:
